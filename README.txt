# Rapido-style website (beginner project)

## Files
- `index.html` - website structure and Bootstrap classes
- `style.css` - small custom styles
- `images/` - image crops taken from the screenshots you provided

## How to run
1. Extract the ZIP file.
2. Open the `rapido_website` folder in VS Code.
3. Open `index.html` with Live Server, or double-click `index.html`.
4. Internet is required for Bootstrap CDN.

## Beginner notes
- Bootstrap grid: `container`, `row`, `col-lg-6`, `col-md-4`
- Bootstrap spacing: `mt-4`, `mb-3`, `py-5`, `g-4`
- Bootstrap components: `navbar`, `btn`, `form-control`, `input-group`
- Custom CSS is in `style.css`.

The booking form currently shows a demo alert. It does not book a real Rapido ride.
